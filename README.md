# 🎒 My Pet's Word Box (Enid & Ian 專屬單字探險箱)

專為 Enid & Ian 雙胞胎打造的互動式國語課本單字學習與複習小遊戲。結合 **Leitner 五箱間隔複習演算法**、**虛擬寵物養成伴讀**、**秋天落葉視覺** 與 **跨裝置自動雲端進度同步**。

---

## ✨ 核心特色

### 1. 🧠 雙軌學習、認讀字支援與 Leitner 間隔重複記憶法
- **生字與認讀字分軌訓練**：
  - **一般生字**：看注音寫國字（認字默寫）＋ 看國字寫注音（讀音檢驗）雙向把關。
  - **二上認讀字（23 字）**：無方框認讀字專屬「單向出題」，僅測驗**看國字寫注音**，不考寫國字，符合國小教學課綱。
- **課本級標準直式注音排版**：二、三、四聲精準依附於最後一個韻母的右上角，輕聲於正上方，完美符合教育部教科書規範。
- **雙軌練習模式（點擊課文自選）**：
  - **🌱 生字初學**：適合初學新課，按部就班（Box 0 ➡️ 2 ➡️ 3...）循序漸進。
  - **🎯 弱點快篩**：全課實戰檢驗；**會寫的直通 Box 5 精通畢業，只有不會寫的才會被抓進 Box 1 每天密集複習**！
- **雙軌練習模式（點擊課文自選）**：
  - **🌱 生字初學**：適合初學新課，按部就班（Box 0 ➡️ 2 ➡️ 3...）循序漸進。
  - **🎯 弱點快篩**：適合考前或多輪複習，全課實戰檢驗；**會寫的直接進 Box 5 精通畢業（不再出現在日常複習），只有不會寫的才會被抓進 Box 1 每天密集複習**！
- **五階卡盒管理（Box 1 ~ Box 5）**：根據艾賓豪斯記憶遺忘曲線，答對晉級、答錯退回 Box 1，高效率鞏固國語生字與注音拼寫。
- **雙向練習模式**：
  - 看注音寫國字（認字與筆畫檢驗）。
  - 看國字寫注音（讀音與聲調複習）。
- **進度即時可視化**：個人學習數據看板，清楚呈現各卡盒掌握率與已精通字數（Mastered）。

### 2. 🐾 專屬虛擬寵物與養成房（Pet Room）
- **雙角色專屬寵物**：
  - 🐱 **Enid**：小白貓伴讀 + 專屬英文鼓勵語。
  - 🐶 **Ian**：小白狗伴讀 + 專屬英文鼓勵語。
- **互動養成系統**：
  - 🍪 餵食餅乾、🥛 暢飲能量飲。
  - 💩 清理房間污漬，培養生活習慣並賺取額外寶石。
  - 互動道具解鎖：數學盆栽 🌿、筆畫水晶球 🔮、特製相框 🖼️。

### 3. 🎬 每月特別影片獎勵（Monthly Movie Hall）
- **每週挑戰與星星累積**：每累積 50 顆寶石兌換 1 顆星星。
- **集滿 7 顆星大獎**：每月達成 7 星任務，即解鎖當月客製化家庭回憶或主題特別影片！

  - 10月：`2026 Oct Basketball Time` 🏀

  - 8月：`2026 Aug Muay Thai` 🥊
  - 7月：`2026 July Elephant` 🐘
  - 6月：`2026 June Dragon Boat` 🚣
  - 5月：`2026 May Pirate Ride Fun` 🏴‍☠️
  - 4月：`2026 April Happy Birthday` 🎂
  - 3月：`2026 March warm mud` 🌾

### 4. 🍂 原創手繪與秋季氛圍
- **向量手繪落葉動畫**：五裂卡通楓葉 🍁 與波浪橡樹葉 🌿 隨風飄落，純 SVG 向量繪製，極致輕量流暢。
- **原生全域 Web Audio 音效**：免載入外部音檔，以振盪器合成輕快過關、獎勵音效。

### 5. ☁️ 跨裝置無感雲端同步（Cloud Sync）
- **多裝置無縫切換**：無論在桌機、筆電或平板上練習，進度自動上傳雲端保存。
- **防覆蓋智慧合併**：自動評估本機與雲端的歷史學習記錄，避免新開裝置覆蓋舊進度。
- **本機離線優先**：無網路時自動切換為本地 LocalStorage，連線後自動同步。

## 🎮 操作指南

1. **選擇挑戰者**：進入首頁點選 **Enid** 或 **Ian** 進入專屬房間。
2. **開始練習**：
   - 點擊「開始練習」依抽卡順序作答。
   - 點選「按課次練習」可針對指定課次重點強化。
3. **寵物互動**：
   - 到「My Pet Room」可自訂寵物名字、餵食、整理房間。
   - 點擊發光的彩虹相框可觀看已解鎖的當月特別影片。
4. **雲端同步狀態**：
   - 每次獲得寶石或更動進度時，右下角會浮現 `☁️ 雲端同步中...` ➔ `✨ 雲端同步完成` 膠囊指示燈。

## 🛠️ 技術架構

- **零依賴單檔架構（Zero-Dependency Single File）**：純 HTML5 + CSS3 + 原生 JavaScript，無需 Node.js 編譯打包環境，雙擊即開。
- **UI 框架**：Tailwind CSS (CDN) + 自定義微動畫。
- **資料儲存**：LocalStorage（本機快照）+ Restful-API Cloud Storage（雲端同步）。
- **圖形與素材**：手繪純 SVG 代碼，維持最高清晰度與極致微型體積。
